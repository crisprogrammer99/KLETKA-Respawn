# Contributing

Thanks for helping improve KLETKA Respawn.

## Bug reports

Please include:

- KLETKA build/version if known
- RE-UE4SS build
- Host/client role
- Number of players
- What you expected
- What actually happened
- Relevant `[KletkaRespawn]` lines from `UE4SS.log`

## Pull requests

Keep changes focused and explain what was tested.

Please avoid bundling:
- RE-UE4SS binaries
- KLETKA game files/assets
- credentials or private logs

## Testing priority

The main open area is reliable automatic respawn during floor transitions while preserving the stable manual F8 behavior.
